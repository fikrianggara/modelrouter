## Description

Memperbaiki celah keamanan kritis VULN-10 (Decision API Key Exfiltration & SSRF via BYOK Test Endpoint & Header Override), VULN-11 (Unauthenticated Decision Provider Hijacking), dan VULN-12 (Plaintext Secret Storage & Non-Atomic Config Write) yang ditemukan pada subsistem BYOK (`docs/private/2026-10-30-security-audit.md`). Mencegah pencurian server secret key saat pemanggilan custom endpoint test atau request header override, mewajibkan proteksi otentikasi pada endpoint mutasi decision provider, serta memastikan penulisan `decision-provider.json` dilakukan secara atomik.

## Acceptance criteria

- [x] Pada endpoint `POST /api/decision-provider/test` di `src/api/server.ts`, jika `body.endpoint` disediakan dan berbeda dari endpoint terdaftar tetapi `body.apiKey` tidak diisi, server dilarang mewariskan `d1Client.apiKey` host; request dikirim tanpa bearer token atau ditolak jika provider membutuhkan kunci
- [x] Pada fungsi `resolveClientForRequest()` di `src/api/server.ts`, jika header `x-decision-endpoint` disertakan oleh klien tanpa header `x-decision-api-key`, server tidak boleh meneruskan `d1Client.apiKey` default ke endpoint pihak ketiga tersebut
- [x] Endpoint mutasi dan pengujian `PUT /api/decision-provider` dan `POST /api/decision-provider/test` dilindungi oleh middleware autentikasi `ADMIN_API_KEY` (mengembalikan 401 Unauthorized jika tidak valid saat auth aktif)
- [x] Fungsi `saveDecisionProviderConfig()` di `src/core/decision-config.ts` diubah menjadi atomik dengan menulis ke file temporary (`${filePath}.tmp.${Date.now()}`) sebelum `fs.renameSync()`, dengan izin file terbatas (`0o600`)
- [x] Unit test di `tests/unit/decision-config.test.ts` memverifikasi penulisan atomik dan penanganan error persistence
- [x] Integration test di `tests/integration/decision-provider-api.test.ts` memverifikasi pencegahan kebocoran API key server ke custom endpoint override dan penolakan akses unauthenticated
- [x] Seluruh test suite vitest lulus 100%
