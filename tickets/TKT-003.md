## Description

Implement the core canonical representation for client requests (`CanonicalRequest`, `CanonicalMessage`, and `CanonicalToolCall`) in `src/core/types.ts`. Implement `CanonicalRequest.extractState()` to produce clean, bounded state strings for System One d1 evaluation from multi-turn dialogues and tool definitions.
