## Description

Memperbaiki celah keamanan VULN-05 (Prompt PII Leakage in Telemetry) dan VULN-06 (Upstream Connection Exhaustion & Memory DoS) dari `docs/private/SECURITY_AUDIT.md`. Menyensor cuplikan prompt pengguna pada buffer telemetri in-memory, menerapkan middleware batas ukuran payload JSON (10MB), serta menambahkan timeout upstream terikat (bounded 60s) pada panggilan fetch reverse proxy.

## Acceptance criteria

- [x] Modul telemetri `src/core/telemetry.ts` tidak lagi menyimpan cuplikan teks prompt mentah (`promptSnippet`) secara terbuka di memori; teks prompt di-hash atau hanya menyimpan metadata panjang karakter dan domain untuk mencegah kebocoran PII/kredensial pada `GET /api/telemetry/recent`
- [x] Middleware pembatas ukuran request body (`bodyLimit` maksimal 10MB) ditambahkan pada server Hono di `src/api/server.ts` untuk mencegah serangan heap memory exhaustion DoS
- [x] Pemanggilan upstream fetch di `src/api/server.ts` (pada rute OpenAI dan Anthropic forwarder) dibatasi dengan timeout terikat (maksimal 60.000ms) menggunakan `AbortSignal` agar koneksi tidak menggantung tanpa batas
- [x] Unit test di `tests/unit/telemetry.test.ts` memverifikasi prompt mentah tidak lagi terekspos dalam objek telemetri
- [x] Integration test memverifikasi penolakan payload request yang melampaui batas ukuran body
- [x] `npx vitest run` seluruh test suite lulus 100%
