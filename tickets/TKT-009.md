## Description

Build modern SPA using Vite, TanStack Router, React, Tailwind CSS, and Lucide Icons. Features an Interactive Complexity Playground with live visual complexity gauge (1-5), domain tagging, token-by-token streaming, a Model Registry visualizer, and live latency & cost-saving telemetry cards.

## Acceptance criteria

- [ ] Vite frontend configured with Tailwind CSS, PostCSS, and TanStack Router
- [ ] Root layout with clean navbar, routing links (Dashboard, Playground, Registry), and health indicator
- [ ] Interactive Playground (`/playground`) with real-time prompt complexity meter, domain classification badges, target model routing card, and streaming chat output
- [ ] Model Registry view (`/registry`) displaying configured models, tags, complexity ranges, and capabilities
- [ ] Build script compiles frontend assets to `dist/client` cleanly (`npm run build`)
- [ ] `npx vitest run` and build checks pass 100%
