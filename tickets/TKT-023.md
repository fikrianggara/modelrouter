## Description

Membangun antarmuka pengguna Web Dashboard untuk pengelolaan Bring Your Own Key (BYOK) decision provider dengan gaya Firecrawl Blueprint. Menyediakan modal settings untuk memilih preset provider (Ollama, Liquid Cloud, Custom), input API key yang aman dengan toggle show/hide, tombol uji koneksi langsung dengan status latensi ping, serta integrasi status provider pada navbar atas.

## Acceptance criteria

- [x] Komponen `DecisionProviderModal` dibuat dengan token desain Firecrawl (border 1px `#EDEDED` / dark `#23252A`, card preset radio, font mono untuk metadata)
- [x] Tersedia pemilih preset: Ollama (Local), Liquid AI (Cloud), dan Custom Endpoint dengan pengisian otomatis endpoint dan model default
- [x] Input API key aman dengan toggle visibilitas show/hide dan indikator key tersimpan (masked display)
- [x] Tombol "Test Connection" memicu panggilan ke `POST /api/decision-provider/test` dan menampilkan status konektivitas serta latensi roundtrip secara real-time
- [x] Tombol "Save & Apply" memperbarui konfigurasi server melalui `PUT /api/decision-provider` dan menampilkan notifikasi sukses
- [x] Status pill pada header navbar (`src/web/routes/__root.tsx`) menampilkan nama provider aktif dan statusnya (misal: `liquid · 142ms · d1:online` atau `ollama · 49ms · d1:online`) dan dapat diklik untuk membuka modal settings
- [x] `npm run build` sukses tanpa peringatan atau kegagalan kompilasi TypeScript
- [x] Seluruh unit dan integration test (`npx vitest run`) lulus 100%
