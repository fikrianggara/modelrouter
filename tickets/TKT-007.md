## Description

Implement `createOpenAIToAnthropicTransform()` and `createAnthropicToOpenAITransform()` in `src/adapters/sse-transcoder.ts`. Uses `eventsource-parser` and Web Standard `TransformStream` to re-encode streaming SSE frames on-the-fly without buffering delays or TCP packet fragmentation issues.

## Acceptance criteria

- [ ] `src/adapters/sse-transcoder.ts` implements `createOpenAIToAnthropicTransform()`
- [ ] `createOpenAIToAnthropicTransform()` converts OpenAI delta chunks to Anthropic `message_start`, `content_block_start`, `content_block_delta`, `content_block_stop`, `message_delta`, and `message_stop` events
- [ ] Handles fragmented SSE buffer reconstruction via `eventsource-parser`
- [ ] `tests/unit/sse-transcoder.test.ts` validates streaming event sequence and partial chunk reconstruction
- [ ] `npx vitest run tests/unit/sse-transcoder.test.ts` passes with 100% success rate
