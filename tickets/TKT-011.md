## Description

Implement 5 core enhancements:
1. Model Registry Management: CRUD operations for models in `config/registry.yaml`, with enable/disable toggling and API endpoints (`POST/PUT/DELETE /api/registry/model`, `PATCH /api/registry/model/:id/toggle`).
2. Maximum D1 timeout updated to 10 seconds (`10000ms`) across backend and configuration.
3. Interactive Decision Flow Graph/Node in UI visualizing the complete evaluation pipeline: Prompt -> D1 Evaluation -> Candidate Filtering -> Policy Selection -> Upstream Dispatch.
4. Dynamic Real-time Telemetry on Homepage: Replace static dashboard metrics with live request counts, real decision latency, actual calculated cost savings, complexity distribution, and live request log.
5. Fix streaming response rationales in Playground so explanations match the actual active policy (Quality-Max, Cost-Optimized, Local-First, Balanced) instead of always defaulting to Pareto text.

## Acceptance criteria

- [ ] `src/engine/registry.ts` supports `enabled` field, `addModel()`, `updateModel()`, `deleteModel()`, `toggleModel()`, `saveToFile()`, and candidate filtering excludes disabled models
- [ ] API endpoints created for model management: `POST /api/registry/model`, `PUT /api/registry/model/:id`, `DELETE /api/registry/model/:id`, `PATCH /api/registry/model/:id/toggle`
- [ ] UI in `/registry` includes Add Model modal/drawer, Edit Model modal, and Enable/Disable toggle switches
- [ ] D1 timeout default increased to 10000ms in `src/core/config.ts`, `.env.example`, `D1Client`, and all tests
- [ ] Interactive Decision Node Graph component added to Playground visualizing the 5-stage decision flow with live metrics
- [ ] Telemetry store implemented in `src/core/telemetry.ts` and exposed via `GET /api/stats` and `GET /api/telemetry/recent`
- [ ] Homepage dashboard (`/`) connects dynamically to `/api/stats` and renders live telemetry, charts, and request table
- [ ] Playground streaming simulation dynamically adapts its rationale text to the active policy (`quality_max`, `cost_optimized`, `local_first`, `balanced`)
- [ ] `npx vitest run` passes 100% and `npm run build` succeeds cleanly
