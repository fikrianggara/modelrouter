## Description

Membangun fondasi Bring Your Own Key (BYOK) untuk decision model di ModelRouter. Memperluas skema konfigurasi dengan variabel lingkungan decision provider, mendefinisikan preset provider (Ollama local, Liquid AI Cloud, Custom), serta memperbarui D1Client untuk mendukung injeksi header Authorization Bearer token dan penanganan error/fallback gracefully.

## Acceptance criteria

- [x] `ConfigSchema` di `src/core/config.ts` mendukung `DECISION_PROVIDER` (`ollama` | `liquid` | `custom`), `DECISION_API_KEY`, `DECISION_ENDPOINT`, `DECISION_MODEL`, dan `DECISION_TIMEOUT_MS` (default: 10000)
- [x] `DECISION_PRESETS` dan tipe `DecisionProviderType` didefinisikan di `src/core/types.ts` dengan default endpoint & model untuk Ollama (`http://localhost:11434/v1/systemone`, `d1:latest`) dan Liquid AI Cloud (`https://api.liquid.ai/v1/systemone`, `d1`)
- [x] `D1Client` di `src/engine/d1-client.ts` menerima opsi `provider`, `apiKey`, `endpoint`, `model`, `timeoutMs`
- [x] `D1Client.evaluate()` menyertakan header `Authorization: Bearer <apiKey>` pada pemanggilan HTTP jika `apiKey` disuplai
- [x] `D1EvaluationResult` menyertakan metadata `provider` yang digunakan
- [x] `D1Client.fallbackEvaluate()` menangani respons 401/403/timeout dari provider cloud dengan fallback deterministik dan `fallbackReason` yang jelas
- [x] Unit tests baru di `tests/unit/d1-client.test.ts` dan `tests/unit/config.test.ts` memvalidasi parsing konfigurasi, pembentukan request Bearer token, dan fallback
- [x] `npx vitest run tests/unit/d1-client.test.ts tests/unit/config.test.ts` berhasil 100%
