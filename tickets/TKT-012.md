## Description

Transform ModelRouter Web UI from a generic AI-SaaS style (rainbow gradients, glowing blobs, uppercase card kits, marketing hype) into a clean, precision-engineered developer appliance and decision inspection console (Linear/Raycast/Cloudflare aesthetic).

## Acceptance criteria

- [ ] Global layout (`__root.tsx`) refactored with minimal wordmark, live d1 status indicator, segmented navigation bar, and clean dark/light mode
- [ ] Dashboard (`index.tsx`) redesigned into an operational control plane with high-density 4-KPI summary bar, live architecture map, and high-density telemetry table
- [ ] Playground (`playground.tsx`) redesigned as an engineering workbench with calibrated complexity spectrum (1.0-5.0), clean prompt editor with policy controls, and live connected Decision Pipeline Graph
- [ ] Model Registry (`registry.tsx`) redesigned as an operational switchboard with clean model cards, instant toggle switches, responsive filters, and sleek edit/add modal
- [ ] Global stylesheet and Tailwind tokens cleaned of neon glow and excessive decorations
- [ ] All 100 existing unit and integration tests in Vitest pass 100%
- [ ] `npm run build` succeeds cleanly with zero TypeScript errors
