## Description

Build modern SPA using Vite, TanStack Router, React, Tailwind CSS, and Lucide Icons. Features an Interactive Complexity Playground with live visual complexity gauge (1-5), domain tagging, token-by-token streaming, a Model Registry visualizer, and live latency & cost-saving telemetry cards.

## Acceptance criteria

- [x] Vite frontend configured with Tailwind CSS, PostCSS, and TanStack Router
- [x] Root layout with clean navbar, routing links (Dashboard, Playground, Registry), and health indicator
- [x] Interactive Playground (`/playground`) with real-time prompt complexity meter, domain classification badges, target model routing card, and streaming chat output
- [x] Model Registry view (`/registry`) displaying configured models, tags, complexity ranges, and capabilities
- [x] Build script compiles frontend assets to `dist/client` cleanly (`npm run build`)
- [x] `npx vitest run` and build checks pass 100%
