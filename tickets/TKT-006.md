## Description

Implement `PolicyEngine` in `src/engine/policy-engine.ts` supporting four routing strategies: `balanced` (closest midpoint distance to complexity score), `cost_optimized` (cheapest model meeting criteria), `quality_max` (highest headroom capability model), and `local_first` (prioritizes zero-cost local Ollama models).

## Acceptance criteria

- [ ] `src/engine/policy-engine.ts` implements `PolicyEngine.resolve()` returning `RoutingDecision`
- [ ] Supports strategies: `balanced`, `cost_optimized`, `quality_max`, and `local_first`
- [ ] Provides decision metadata: `selectedModel`, `policyUsed`, `reason`, and `complexityScore`
- [ ] Handles empty candidates gracefully with explicit error
- [ ] `tests/unit/policy-engine.test.ts` validates all policy strategies and tie-breaking
- [ ] `npx vitest run tests/unit/policy-engine.test.ts` passes with 100% success rate
