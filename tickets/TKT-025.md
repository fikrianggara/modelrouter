## Description

Memperbaiki celah keamanan VULN-02 (Unauthenticated Registry Tampering), VULN-03 (Permissive CORS Wildcard), dan VULN-08 (Unauthenticated Public Proxy / Default Binding 0.0.0.0) dari `docs/private/SECURITY_AUDIT.md`. Mengubah default binding host menjadi `127.0.0.1`, memperketat CORS policy agar tidak menggunakan wildcard `*` pada endpoint sensitif, serta menambahkan proteksi autentikasi opsional `ADMIN_API_KEY` untuk rute mutasi `/api/*`.

## Acceptance criteria

- [ ] Variabel `HOST` di `src/core/config.ts` diubah default-nya dari `0.0.0.0` menjadi `127.0.0.1` untuk mencegah pembukaan port ke jaringan publik secara tidak sengaja
- [ ] Menambahkan variabel lingkungan opsional `ADMIN_API_KEY` pada `ConfigSchema` di `src/core/config.ts`
- [ ] Middleware autentikasi di `src/api/server.ts` melindungi rute mutasi `/api/registry/*` dan endpoint sensitif lainnya ketika `ADMIN_API_KEY` disetel; request tanpa header `Authorization: Bearer <ADMIN_API_KEY>` ditolak dengan HTTP 401 Unauthorized
- [ ] Konfigurasi CORS di `src/api/server.ts` diperketat sehingga tidak mengizinkan wildcard `*` tanpa batas pada rute-rute mutasi administratif internal
- [ ] Dashboard Web tetap dapat berinteraksi dengan API internal saat berjalan pada origin lokal yang sama atau origin terdaftar
- [ ] Integration test di `tests/integration/web-server.test.ts` memverifikasi proteksi 401 ketika `ADMIN_API_KEY` aktif dan respons 200 ketika token yang valid disertakan
- [ ] Seluruh integration test lulus 100%
