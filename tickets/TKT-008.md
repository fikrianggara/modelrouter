## Description

Implement Hono API server in `src/api/server.ts` with dual standard endpoints: `POST /v1/chat/completions` (OpenAI), `POST /v1/messages` (Anthropic), and `GET /v1/models`. Integrates D1 evaluation, policy resolution, upstream forwarding, SSE transcoding, and telemetry headers (`X-D1-Complexity-Score`, `X-D1-Domain`, `X-D1-Selected-Model`, `X-D1-Routing-Latency-Ms`).

## Acceptance criteria

- [x] `GET /v1/models` returns list of virtual router models and registered models
- [x] `POST /v1/chat/completions` routes requests to evaluated model and supports streaming & non-streaming responses
- [x] `POST /v1/messages` routes requests with Anthropic format and transcodes SSE streaming when targeting OpenAI upstream
- [x] Response headers include `X-D1-Complexity-Score`, `X-D1-Domain`, `X-D1-Selected-Model`, and `X-D1-Routing-Latency-Ms`
- [x] `tests/integration/gateway.test.ts` validates all endpoints with mocked upstream and d1
- [x] `npx vitest run tests/integration/gateway.test.ts` passes with 100% success rate
