## Description

Refactor ModelRouter web interface to strictly adopt the Firecrawl design system: signature heat orange (`#fa5d19`) brand moments, near-neutral surfaces (`#f9f9f9`/`#0a0a0a` base, `#ffffff`/`#171717` surface, `#1f1f1f` raised), `border-muted` (`#e8e8e8`/`#333333`), semantic accents (`forest`, `honey`, `crimson`, `bluetron`), signature warm stacked shadow on primary action buttons, 8px/12px radius hierarchy, and precise typography.
