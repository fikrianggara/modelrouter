## Description

Membangun endpoint API manajemen decision provider, layer persistensi konfigurasi ke `config/decision-provider.json`, pengujian koneksi live (test connection ping), serta dukungan override BYOK per-request menggunakan header HTTP `X-Decision-*` pada gateway OpenAI dan Anthropic.

## Acceptance criteria

- [x] File persistensi `config/decision-provider.json` dibuat/dibaca untuk menyimpan setelan runtime provider saat server dimulai kembali (restart)
- [x] Endpoint `GET /api/decision-provider` mengembalikan konfigurasi provider aktif, daftar preset, `hasApiKey`, dan masked API key (`sk-liq-...xxxx`), tanpa membocorkan raw secret key
- [x] Endpoint `PUT /api/decision-provider` memvalidasi input dengan Zod, memperbarui singleton decision client secara runtime, dan menyimpan perubahan ke file JSON konfigurasi
- [x] Endpoint `POST /api/decision-provider/test` menguji konektivitas endpoint target dengan mengirimkan payload evaluasi uji ringan, mengukur latensi roundtrip, dan mengembalikan status koneksi
- [x] Gateway `/v1/chat/completions`, `/v1/messages`, dan `/api/evaluate` mendukung header override per-request: `X-Decision-Provider`, `X-Decision-Api-Key`, `X-Decision-Endpoint`, `X-Decision-Model`
- [x] Header response audit `X-D1-Provider` disematkan pada setiap respons gateway yang dievaluasi
- [x] Modul telemetri (`src/core/telemetry.ts`) mencatat identifier provider yang digunakan untuk setiap evaluasi
- [x] Integration tests di `tests/integration/web-server.test.ts` dan `tests/integration/gateway.test.ts` memvalidasi seluruh rute API dan mekanisme override per-request
